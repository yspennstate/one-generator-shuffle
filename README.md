# Adding one permutation to a transposition and a long cycle

Yitzchak Shmalo

Paper: [paper/main.pdf](paper/main.pdf) (source [paper/main.tex](paper/main.tex)).

For odd $n$, the random walk on $S_n$ generated by the transposition $(1,2)$ and the $n$-cycle $(1,2,\dots,n)$
needs order $n^3\log n$ steps to mix. Diaconis (Some things we've learned (about Markov chain Monte Carlo),
Bernoulli 19 (2013), Question 3) asked whether adding one more permutation can speed it up appreciably. The paper
shows that adding the doubling map $x\mapsto 2x \bmod n$ of $\mathbb Z/n\mathbb Z$ reduces the mixing time of the
half-lazy walk to $O(n\log^3 n)$, and that whatever permutation is added the walk needs order $n\log n$ steps.
The exact order, and which added permutation attains it, remain open.

## Code

Both scripts need Python 3; `mixing_table.py` also needs numpy.

- `code/check_words.py [nmax]` builds the words of Lemmas 2.1 and 2.2 for every odd $n$ from 5 to `nmax`
  (default 301), evaluates them as permutations, and checks that they are correct and no longer than the bounds.
- `code/mixing_table.py` computes the exact mixing times in the table of Section 5 for $n=5,7,9$, and the
  search over all 120 added permutations for $n=5$. Its output is in `code/mixing_table_output.txt`.
